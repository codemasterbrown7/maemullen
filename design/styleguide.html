00How to use this document

Two decisions to make, in this order. Part 1 gives you four complete colour directions — the brand colours are fixed by the deck, so what changes is which colour does which job: the page, the buttons, the accent. Part 2 compares three heading typefaces. Part 3 is the shared detail — ramps, scale, states, contrast — that applies whichever you pick.

Once you choose, these become the rules and nothing in the build strays from them.

01Part 1 · Choose a colour direction

Same six brand colours in all four. What differs is the role each one plays — and that changes the whole feel. Each card shows the roles, the buttons, and a preview so you can read the vibe rather than imagine it.

02Part 2 · Choose a heading typeface

The logotype is a supplied image, so this face is only for headings — it has to sit beside the wordmark, not match it. Your "Mae" is set heavy, which is the thing to judge against: a light heading face reads as deliberate contrast, or as a mismatch.

03Part 3 · Brand palette

Fixed by the deck. I sampled the supplied logo files and all values match exactly.

04Colour ramps & usage rules

Tints and shades derived from each brand colour, for hovers, borders, tinted panels and disabled states. The 500 step is always the true brand value — never invent a new one.

05Type scale

Fluid sizes. Display styles are set tight; body is set loose for reading.

06Buttons & states

Three tiers. Every interactive element carries all five states — including a visible focus ring, which is never removed.

07Spacing

4px base. Nothing off-scale — if a value is missing, extend the scale rather than improvise.

08Contrast — computed, not estimated

Calculated live in the browser from the hex values above. WCAG 2.1: body text needs 4.5:1, large text (≥24px) needs 3:1. This is the constraint that shapes the options in Part 1.
